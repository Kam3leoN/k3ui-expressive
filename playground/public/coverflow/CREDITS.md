# Cover flow demo images — credits & licences

Every image here is free of rights: public domain or CC0 1.0. No attribution is
required; it is given below for provenance. `full/` holds the lightbox images
(≤ 1200 px), the folder root the 448 px square covers.

Regenerate with `python3 scripts/coverflow-art.py` (numpy, pillow, scikit-image).

## Painted from code — CC0 1.0 (K3UI contributors)

`lake-reflection`, `lavender-hills`, `starry-valley`, `red-canyon`, `moonrise`.
