Quick Start

Quick Start

Install and use K3ui web components in Angular, React, Vue, or plain HTML.

Pick a path that matches your stack. CDN for a quick try in plain HTML, npm when you already have a bundler, or the framework notes for Angular, React, and Vue. After install, call K3UI.init once, import k3ui.css, and register only the components you use so first paint stays light.

Material 3 Web Component Framework agnostic

CDN — no build step

Import the bundle from a CDN. Works in any modern browser with no tooling. 

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/k3ui/k3ui.css" />
<script type="module" src="https://cdn.jsdelivr.net/npm/k3ui/+esm"></script>

<k3-button variant="filled">Click me</k3-button>

Install via package manager

Add the package, import CSS + init, then use the tags in your app. 

npm install k3ui
pnpm add k3ui
import { K3UI } from 'k3ui';
import 'k3ui/k3ui.css';

await K3UI.init({
  locale: 'en',
  theme: { seed: '#6750A4', mode: 'auto', motion: 'expressive' },
});

Angular

Add CUSTOM_ELEMENTS_SCHEMA so unknown k3-* tags are allowed. 

import { Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';
import 'k3ui';
import 'k3ui/k3ui.css';

@Component({
  selector: 'app-root',
  template: `<k3-button variant="filled">Angular</k3-button>`,
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
})
export class AppComponent {}

React

React 19+ supports Custom Elements natively. Prefer refs for custom events. 

import React from 'react';
import 'k3ui';
import 'k3ui/k3ui.css';

export default function App() {
  return (
    <k3-button variant="filled" onClick={() => console.log('ok')}>
      React
    </k3-button>
  );
}

Vue

Vue supports Custom Elements natively — use @click and v-model where needed. 

<script setup>
import 'k3ui';
import 'k3ui/k3ui.css';
</script>

<template>
  <k3-button variant="filled" @click="() => {}">
    Vue
  </k3-button>
</template>

Buttons Icon

Icon buttons help people take minor actions with a single tap — ideal when space is tight and the action is clear from the icon alone.

Use them in app bars, toolbars, cards, and media controls. Choose a color style by emphasis: filled for the highest, then tonal, outlined, and standard for the lowest. Material 3 Expressive adds five sizes, round or square shapes, and narrow, default, or wide widths — with shape morph on press and when selected. Toggle icon buttons hold a binary state such as favorite or mute; prefer an outlined icon when off and a filled one when on. Always provide an accessible name that describes the action, not the glyph, and keep a ≥48dp touch target on extra-small and small sizes.

Usage

Copy-paste snippets to drop k3-icon-button into a project — HTML markup, optional CSS, and JS init + toggle listener. 

<!-- Default action — label is the accessible name -->
<k3-icon-button label="Favorite" variant="filled">
  <span class="ms notranslate" translate="no" lang="zxx" data-k3-icon="favorite" aria-hidden="true"></span>
</k3-icon-button>

<!-- Sizes · shapes · widths -->
<k3-icon-button label="Edit" size="md" shape="square" width="wide" variant="tonal">
  <span class="ms notranslate" translate="no" lang="zxx" data-k3-icon="edit" aria-hidden="true"></span>
</k3-icon-button>

<!-- Toggle — optional selected-icon when on -->
<k3-icon-button toggle label="Add to favorites" variant="standard">
  <span class="ms notranslate" translate="no" lang="zxx" data-k3-icon="favorite" aria-hidden="true"></span>
  <span class="ms notranslate" translate="no" lang="zxx" data-k3-icon="favorite" slot="selected-icon" aria-hidden="true"></span>
</k3-icon-button>
/* Optional — k3ui.css already ships .ms + [data-k3-icon]::before */
.ms {
  font-family: "Material Symbols Rounded", "Material Symbols Outlined", sans-serif;
  font-feature-settings: "liga";
  font-variation-settings: "FILL" 0, "wght" 400, "GRAD" 0, "opsz" 24;
  line-height: 1;
  speak: never;
}
.ms[data-k3-icon]::before {
  content: attr(data-k3-icon);
  font-feature-settings: "liga";
}

/* Fine-tune via host attrs (size / shape / width / variant).
   CSS vars are set by the component — override only if needed: */
k3-icon-button {
  /* --k3-ib-h: 2.5rem; */
  /* --k3-ib-icon: 1.5rem; */
}

  locale: "en",

Utilities

Media hotkeys

Space/K · ←/→ · N/P · M — bindMediaHotkeys on top of K3UI.keyboard (powers k3-audio-player).

Media shortcuts reuse the keyboard utility: Space/K toggle, arrows seek, N/P next/prev, M mute. bindMediaHotkeys skips focused fields and is what k3-audio-player enables with the hotkeys attribute.

Shortcut map

Default seek step ±5 s — override with seekStepSec. 

import { bindMediaHotkeys } from 'k3ui';

bindMediaHotkeys({
  toggle: () => player.toggle(),
  seekBy: (d) => player.seek(player.currentTime + d),
  next: () => player.next(),
  prev: () => player.prev(),
  mute: () => player.setMusicMuted(!player.muted),
}, { seekStepSec: 5, enabled: () => player.hotkeys });

Utilities

Scrollbar

Discreet edge scrollbar — .k3-scroll · edgeScrollbarStyles (no Windows arrows).

K3 scrollbars stay discreet on the edge — a slim thumb without Windows arrows. Apply .k3-scroll in light DOM or edgeScrollbarStyles inside shadow roots, override size tokens when needed, and pad an inner child instead of fighting WebKit scrollbar-width.

Live demo

Thumb flush to the right edge · 6dp · transparent track.

Usage in components

Shadow CE → edgeScrollbarStyles + class k3-scroll. Light DOM → global .k3-scroll from k3ui.css. 

/* Shadow custom element */
import { css } from 'lit';
import { edgeScrollbarStyles } from 'k3ui'; // or '../../core/index.js'

static styles = [
  hostReset,
  edgeScrollbarStyles,
  css`
    .panel { display: flex; flex-direction: column; overflow: hidden; }
    .body { flex: 1; min-height: 0; }
    .body-inner { padding-inline: 1.5rem; } /* pad child, not scrollport */
  `,
];

// render:
// <div class="body k3-scroll">
//   <div class="body-inner">…content…</div>
// </div>

/* Light DOM / playground */
<div class="k3-scroll" style="max-height: 12rem">…</div>

/* Optional tokens on the scrollport */
.k3-scroll {
  --k3-scroll-size: 0.5rem;          /* thicker (side sheet) */
  --k3-scroll-track-inset: 0.5rem;   /* clear rounded corners */
}

Hard rules

Pad an inner child · never set scrollbar-width on WebKit with ::-webkit-scrollbar.

  • Already wired: k3-dialog body · k3-sheet side .content
  • Agent rule: .cursor/rules/edge-scrollbar.mdc
  • Keep src/core/scrollbar.ts ↔ src/tokens/_scrollbar.scss in sync
