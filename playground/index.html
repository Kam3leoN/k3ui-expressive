Icon buttons help people take minor actions with a single tap — ideal when space is tight and the action is clear from the icon alone.

Spacing

space100 = 8dp baseline — tokens + .k3-p/m/gap helpers · breakpoints sm→xl.

Spacing follows an 8 dp baseline (space100) through space0…900, plus layout gutter and margins. Prefer CSS variables or the .k3-p-* / .k3-m-* / .k3-gap-* helpers (logical properties, mobile-first sm·md·lg·xl) so density and breakpoints stay aligned with Material 3.

Helpers

Display, flex, padding, margin, gap, and visibility — all prefixed .k3- with optional breakpoint infix.

Breakpoints (min-width): sm 600 · md 905 · lg 1240 · xl 1440. Example: .k3-md-flex .k3-md-gap-200 .k3-p-100.

Padding / margin / gap: .k3-p-{step} · .k3-pt/pb/ps/pe/px/py · .k3-m-* (+ auto) · .k3-gap- / gap-x / gap-y. Full space0…900 at base; responsive infix uses 0·50·100·150·200·300·400·600.
